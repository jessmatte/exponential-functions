Exponentialfunktioner: Formel, Graf & Text

Startvärde C, förändringsfaktor a, upprepningar x och grafer

📘 Snabbguide: Exponentialfunktioner
1. Formeln: f(x) = C · ax Upprepad förändring
C Startvärdet: Värdet från början (när x = 0). Här skär grafen y-axeln.
a Förändringsfaktorn (FF): Talet du multiplicerar med i varje steg (a > 0).
x Antal upprepningar: Hur många steg förändringen sker (t.ex. år eller timmar).
Så beräknar du förändringsfaktorn a:
  • • Från procent (utgå alltid från 100 % = 1):
    Ökning p %: a = 1 + p/100  |  Minskning p %: a = 1 − p/100
  • • Från graf eller tabell (1 steg i x):
    Dividera ett värde med värdet steget före: a = f(1) / f(0) = y2 / y1
  • • Om x hoppar flera steg (t.ex. 2 steg):
    a2 = f(2) / f(0) ⇒ a = √(f(2) / f(0))
2. Grafens riktning & Funktionstyper Uppåt / Nedåt
↗ Ökning: a > 1 (t.ex. +12 % → a = 1,12)

När C > 0 och a > 1 växer värdet snabbare och snabbare — grafen böjer uppåt åt höger.

↘ Minskning: 0 < a < 1 (t.ex. −15 % → a = 0,85)

När C > 0 och 0 < a < 1 minskar värdet och flackar ut — grafen böjer nedåt åt höger.

Känn igen grafen:

• Linjär (kx + m): Rät linje (konstant ökning/minskning).
• Exponential (C · ax): Böjd kurva (procentuell förändring).
• Andragrads (ax2 + bx + c): Symmetrisk U- eller ∩-formad parabel.
