Exponentialfunktioner: Formel, Graf & Text

Startvärde C, förändringsfaktor a, upprepningar x och grafer

Snabbguide: Exponentialfunktioner
1. Formeln f(x) = C · ax Upprepad procent
  • C = Startvärdet: Värdet från början (när x = 0). Här skär grafen y-axeln.
  • a = Förändringsfaktorn (FF): Talet du multiplicerar med varje steg (a > 0).
  • x = Antal upprepningar: Hur många gånger förändringen sker (t.ex. år, timmar eller steg).
  • Beräkna f(8): Sätt in x = 8 och räkna ut C · a8 med miniräknaren.
2. Procent → FF & Grafens form Uppåt / Nedåt
  • Ökning med p %: a = 1 + p/100 (t.ex. +12 % → a = 1,12). För C > 0, a > 1 böjer grafen uppåt.
  • Minskning med p %: a = 1 − p/100 (t.ex. −15 % → a = 0,85). För C > 0, 0 < a < 1 böjer grafen nedåt.
  • Jämför grafer: Linjär (kx + m) = rät linje; Exponential (C · ax) = böjd kurva; Andragrads (ax2 + bx + c) = symmetrisk parabel.
